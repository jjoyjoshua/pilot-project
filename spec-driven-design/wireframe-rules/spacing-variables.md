# Wireframe Rules — Spacing Variables

All spacing values come from this scale only. No arbitrary values.

| Token name | Value | Use |
|------------|-------|-----|
| space-2 | 2px | Micro gaps (icon to label) |
| space-4 | 4px | Tight internal spacing |
| space-8 | 8px | Default internal padding |
| space-12 | 12px | Medium internal padding |
| space-16 | 16px | Default gap between elements |
| space-24 | 24px | Section internal padding |
| space-32 | 32px | Large section padding |
| space-48 | 48px | Between major sections |
| space-64 | 64px | Page-level vertical rhythm |
| space-80 | 80px | Hero / feature section spacing |

## How to Apply
- Component padding: space-8 (vertical), space-16 (horizontal)
- Between components: space-16 or space-24
- Between sections: space-48
- Page top margin: space-64

## Figma Setup
Create as Number Variables under `spacing/` collection.

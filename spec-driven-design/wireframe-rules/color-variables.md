# Wireframe Rules — Greyscale Color Variables

No brand colours in wireframes. Use only these variables.

| Token name | Hex (light) | Use |
|------------|-------------|-----|
| color/surface/default | #FFFFFF | Page background |
| color/surface/raised | #F5F5F5 | Cards, panels |
| color/surface/overlay | #EEEEEE | Hover states, overlays |
| color/border/default | #E0E0E0 | Component borders |
| color/border/strong | #BDBDBD | Dividers, emphasis |
| color/text/primary | #1A1A1A | Headings, primary body |
| color/text/secondary | #616161 | Subheadings, labels |
| color/text/tertiary | #9E9E9E | Placeholder, captions |
| color/text/disabled | #BDBDBD | Disabled states |
| color/action/placeholder | #D0D0D0 | Button fills (wireframe) |
| color/action/strong | #424242 | Primary action fills |

## Figma Setup
Create as Color Variables under `wireframe/` collection.

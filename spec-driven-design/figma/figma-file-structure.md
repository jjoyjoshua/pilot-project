# Figma File Structure — Pilot Project Design System

## Master File
**File name:** `Pilot Project — Design System`

---

## Pages

Wireframe and mockup pages (marked `[generated]`) are created **after** the screen inventory is confirmed in Phase 1 (Discovery) and finalised in Phase 4 (IA). Screen IDs and names are derived from PRD analysis — not assumed in advance.

| Page | Content | When created |
| ---- | ------- | ------------ |
| `_Index` | File navigation guide, phase status tracker, sign-off log | On file creation |
| `01 · Discovery` | Requirements audit summary, competitor analysis frames, scope + screen inventory, assumption log | After Phase 1 |
| `02 · User research` | Participant summary cards, cross-participant pattern board, key quotes highlight board | After Phase 2 |
| `03 · Synthesis` | Affinity map, persona cards, journey map(s), HMW statements, core insights | After Phase 3 |
| `04 · Information architecture` | Sitemap diagram, navigation flow diagrams, card sort results, labelling decisions | After Phase 4 |
| `05 · UX strategy` | Design principles (poster format), UX brief document, success metrics, feature priority (MoSCoW) | After Phase 5 |
| `06 · Concept validation` | Tested concept frames, assumption map, validation findings, go/no-go decisions | After Phase 6 |
| `07 · Wireframe system` | Grid styles reference, spacing variable reference, greyscale color reference, lo-fi component set | Before wireframing |
| `08 · Wireframes — [SCR-ID · Screen name]` | One page per screen — wireframe frame + spec annotation panel | **[generated] After screen inventory confirmed** |
| `09 · Design system — Foundations` | Color system (all three layers), typography scale, spacing + sizing tokens, elevation + radius | After wireframe sign-off |
| `10 · Design system — Components` | Component library, variant matrices, usage guidelines per component | After foundations confirmed |
| `11 · Mockups — [SCR-ID · Screen name]` | One page per screen — hi-fi frame + spec annotation + dev handoff notes | **[generated] After design system sign-off** |

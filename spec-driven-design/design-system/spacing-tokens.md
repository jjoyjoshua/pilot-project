# Design System — Spacing & Sizing Tokens

## Border Radius
| Token | Value | Use |
|-------|-------|-----|
| radius-none | 0px | Sharp edges (tables, code blocks) |
| radius-sm | 4px | Subtle (inputs, small cards) |
| radius-md | 8px | Default (cards, buttons, panels) |
| radius-lg | 12px | Prominent cards, modals |
| radius-xl | 16px | Featured cards, drawers |
| radius-2xl | 24px | Hero elements |
| radius-full | 9999px | Pills, avatars, toggles |

## Elevation (Shadows)
| Token | Value | Use |
|-------|-------|-----|
| elevation-0 | none | Flat / no elevation |
| elevation-1 | 0 1px 2px rgba(0,0,0,0.05) | Cards on white bg |
| elevation-2 | 0 4px 6px rgba(0,0,0,0.07) | Dropdowns, popovers |
| elevation-3 | 0 10px 15px rgba(0,0,0,0.1) | Modals, drawers |
| elevation-4 | 0 20px 25px rgba(0,0,0,0.12) | Full-screen overlays |

## Icon Sizes
| Token | Value |
|-------|-------|
| icon-xs | 12px |
| icon-sm | 16px |
| icon-md | 20px (default) |
| icon-lg | 24px |
| icon-xl | 32px |

## Component Sizes (Heights)
| Token | Value | Use |
|-------|-------|-----|
| size-xs | 24px | Small tags, dense table rows |
| size-sm | 32px | Small buttons, compact inputs |
| size-md | 40px | Default inputs, buttons (primary) |
| size-lg | 48px | Large inputs, prominent CTAs |
| size-xl | 56px | Hero CTAs |
